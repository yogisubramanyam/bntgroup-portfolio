HRMS Platform

The full employee lifecycle — people, attendance, leave, and payroll — in one system.

The problem

A growing company was running HR operations across disconnected tools and spreadsheets — no single source of truth for employee records, attendance, leave, or payroll.

What I built

Architected and built the platform end to end: a server-side-rendered Next.js frontend on a modular NestJS backend with a PostgreSQL data layer and JWT role-based access control. Containerized with Docker, automated build/test/deploy through GitHub Actions, served behind Nginx in a production cloud environment with monitoring.

Role: architect & sole full-stack developer — design to production.

Key features

  • Employee management with role-based dashboards
  • Attendance and leave modules with approvals
  • Payroll module on a clean PostgreSQL data model
  • JWT authentication with role-based access control
  • Dockerized CI/CD — automated, repeatable production deploys

ATS Migration

A hiring platform moved from a low-code prototype to a real stack — 40% faster than estimated.

The problem

The applicant-tracking product had outgrown the low-code builder it was prototyped on — the team needed a codebase they could extend, test, and deploy on their own terms.

What I built

Managed the technical transition to a custom React and Node.js stack, using AI-augmented development (Cursor, Claude Code) for high-speed prototyping — cutting the estimated timeline by roughly 40% — and set up the CI/CD pipeline for automated, repeatable deployments.

Role: technical lead for the migration — stack, code, and pipeline.

Key features

  • Custom React frontend + Node.js backend
  • Full ownership replacing the low-code builder
  • AI-augmented prototyping (~40% faster delivery)
  • CI/CD pipeline for repeatable deployments
